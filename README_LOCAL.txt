أهلاً بك في النسخة المحلية من نظام "محيط المعرفة" (Knowledge Ocean v9.5).
تم تصميم هذا النظام للبحث والاستكشاف الأكاديمي الشامل عبر أكثر من 10 محركات بحث
أكاديمية موثوقة (Crossref, PubMed, Europe PMC, OpenAlex, Scopus, Semantic Scholar,
DOAJ, CORE, Zenodo, Google Books, Open Library).

-------------------------------------------------------------------------------
1. كيفية التشغيل السريع:
-------------------------------------------------------------------------------
1. انقر نقراً مزدوجاً على ملف:
   run_local.bat

2. سيقوم الملف آلياً بالآتي:
   - التأكد من وجود لغة بايثون Python على جهازك (وتثبيتها تلقائياً إن لم تكن متوفرة).
   - إنشاء بيئة عمل معزولة venv وتثبيت المتطلبات إن لم تكن مثبتة مسبقاً (ولا يعيد تثبيتها عند توفرها).
   - قراءة إعداداتك من ملف config.txt تلقائياً.
   - تشغيل الخادم المحلي على الرابط:
     http://localhost:7860/
   - فتح المتصفح تلقائياً للانتقال مباشرة إلى الواجهة الأكاديمية.

-------------------------------------------------------------------------------
2. ملف الإعدادات المحلي (config.txt) وشرح خياراته:
-------------------------------------------------------------------------------
يحتوي مجلد البرنامج على ملف إعدادات نصي باسم:
config.txt

يمكنك فتحه وتعديله في أي وقت باستخدام برنامج المفكرة (Notepad). يحتوي الملف على:

[1] APP_PASSWORD = 123
    - النسخة المحلية تعمل تلقائياً بصلاحية كاملة ومفتوحة دون الحاجة لإدخال أي رمز.
    - يُتاح لك استخراج الأبحاث بلا حدود وبلا قيود، مع تنزيل الملخصات الكاملة لجميع الأوراق داخل ملفات PDF.
    - يمكنك الاحتفاظ بالقيمة الافتراضية 123 أو تعديلها اختيارياً.

[2] UNPAYWALL_EMAIL = contact@example.com
    - البريد الإلكتروني الخاص بك كمستخدم أو باحث.
    - يُستخدم هذا البريد في بروتوكول Polite Pool المعتمد لدى Unpaywall و Crossref.
    - فائدته: تسريع وتيرة الاستعلام ومنحك أولوية في استرجاع الروابط المجانية المباشرة
      للأبحاث ذات الوصول الحر (Open Access PDFs).

[3] ELSEVIER_API_KEY = 
    - مفتاح الربط البرمجي الخاص بدار النشر العالمية إلسيفير (Elsevier / Scopus API Key).
    - هذا الخيار مخصص للباحثين أو منسوبي الجامعات الذين يمتلكون اشتراكاً رسمياً في Scopus.
    - إذا وضعت مفتاحك هنا، سيتصل النظام بقاعدة Scopus مباشرة لجلب النتائج المفهرسة فيها.
    - إذا تركته فارغاً، سيعمل النظام بكامل طاقته عبر المحركات الأكاديمية التسعة الأخرى.

-------------------------------------------------------------------------------
3. متطلبات النظام:
-------------------------------------------------------------------------------
- نظام التشغيل: Windows 10 أو Windows 11.
- اتصال نشط بالإنترنت للاتصال بمحركات البحث الأكاديمية العالمية.
- بايثون: الإصدار 3.10 أو أحدث (يتكفل سكريبت run_local.bat بتهيئته تلقائياً).

-------------------------------------------------------------------------------
4. إيقاف السيرفر:
-------------------------------------------------------------------------------
لإيقاف السيرفر في أي وقت، اضغط على مفتاحي (Ctrl + C) داخل نافذة موجه الأوامر (Terminal)
أو قم بإغلاق النافذة ببساطة.
