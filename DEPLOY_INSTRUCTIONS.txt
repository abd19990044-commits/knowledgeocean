تم تجهيز هذا المجلد (HuggingFace_Space) ليحتوي حصرياً على كافة الملفات النقية
والضرورية لتشغيل محيط المعرفة على Hugging Face Spaces عبر Docker،
دون أي ملفات زائدة أو بيئات افتراضية محلية.

-------------------------------------------------------------------------------
1. محتويات المجلد الجاهزة:
-------------------------------------------------------------------------------
- Dockerfile             : ملف بناء حاوية الدوكر المتوافقة مع Hugging Face.
- README.md              : ترويسة البيانات الوصفية (Metadata) لـ HF (sdk: docker).
- requirements.txt       : حزم ومكتبات بايثون الأساسية.
- app.py وكافة ملفات المحرك الأكاديمي (.py).
- templates/             : واجهة المستخدم مع زر وتحميل النسخة المحلية.
- fonts/                 : الخطوط العربية والإنجليزية المعتمدة لملفات الـ PDF.
- downloads/             : يتضمن حزمة التشغيل المحلي الجاهزة (KnowledgeOcean_Local.zip).

-------------------------------------------------------------------------------
2. خطوات الرفع إلى Hugging Face:
-------------------------------------------------------------------------------

[الطريقة الأولى: الرفع عبر متصفح الويب (سحب وإفلات)]
1. ادخل إلى حسابك في Hugging Face وأنشئ Space جديداً:
   https://huggingface.co/new-space
   - اختر الاسم الذي تريده (مثال: knowledge-ocean).
   - في خانة Select the Space SDK: اختر Docker ثم Blank.
2. بعد إنشاء الـ Space، اذهب إلى تبويب Files and versions.
3. اضغط على Add file -> Upload files.
4. اسحب كافة محتويات هذا المجلد (HuggingFace_Space) وأفلتها في المتصفح.
5. اضغط Commit changes to main.
6. سيبدأ Hugging Face بالبناء (Building) ثم ينطلق السيرفر تلقائياً (Running).

---

[الطريقة الثانية: الرفع عبر Git (سريع ومباشر)]
افتح موجه الأوامر داخل هذا المجلد (HuggingFace_Space) ونفذ:

    git init
    git branch -M main
    git add .
    git commit -m "Deploy Knowledge Ocean v9.5 to Hugging Face"
    git remote add origin https://huggingface.co/spaces/YOUR_USERNAME/YOUR_SPACE_NAME
    git push -u origin main --force

-------------------------------------------------------------------------------
3. إعداد الأسرار والمتغيرات الاختيارية (Secrets):
-------------------------------------------------------------------------------
في صفحة الـ Space على Hugging Face، اذهب إلى:
Settings -> Variables and secrets -> New secret
- APP_PASSWORD      : رمز الدخول لكبار الباحثين (123 أو مخصص).
- UNPAYWALL_EMAIL   : بريدك للاتصال الأكاديمي السريع (Polite Pool).
- ELSEVIER_API_KEY  : مفتاح ربط Scopus (إن وجد).
